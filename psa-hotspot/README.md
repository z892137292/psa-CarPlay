# PSA Hotspot v0.1
独立 Android 9 横屏测试应用，包名 com.psa.hotspothelper。不会启动或修改 PSA CarPlay。

四个按钮：开启热点、关闭热点（均进入系统设置手动操作）、检测连接、查看日志。前台每3秒读取状态；后台停止检测。只声明 Wi-Fi/网络状态读取权限，无联网权限，不读取热点密码，不修改系统或启动流量共享。

名称显示系统可读取的配置，关闭时可能是保存的名称。IP仅显示系统报告且匹配系统Wi-Fi共享规则的接口IPv4地址及接口名，无权读取时显示未知。接入数为厂商接口返回值，不证明是iPhone，亦不能保证实时。不可读取不表示热点关闭。

工具箱受保护，尚未确认其实际入口。本版尝试常见热点页面及两个显式设置Activity，失败可选择网络/系统设置。必须在真实PSA车机确认入口、状态和布局。

日志保留最近200条，可查看/复制/清空。没有开机恢复、自动开关或CarPlay重连功能。开发签名测试APK，不能保证覆盖此前助手；正式固定签名后再承诺覆盖升级。
