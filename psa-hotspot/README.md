# PSA Hotspot v0.2 Wi-Fi Direct 验证版
独立 Android 9 横屏应用，包名 com.psa.hotspothelper，不改动 PSA CarPlay。

保留系统热点设置跳转、只读状态检测和日志。新增 Wi-Fi Direct 测试入口：
- 开启车机Wi-Fi和定位，授予定位权限。应用不读取定位坐标。
- 先手动关闭原热点以减少驱动冲突，再点创建测试网络。
- 使用 Android 9 的 createGroup旧接口，让系统生成SSID/密码；不保证5GHz。只在系统提供频率时显示实际值。
- 系统接受创建请求并不代表成功；等实际组信息出现后显示网络名、接口IPv4、组主状态和密码。
- 在iPhone Wi-Fi设置尝试加入；本版没有CarPlay握手或流量测试，也不共享移动流量。
- 客户端数量是系统P2P客户端列表，可能不计普通Wi-Fi客户端，不能用来判定iPhone已接入。
- 前台Service保持测试组，返回主界面不主动删除。结束点停止测试，仅删除本进程已确认创建的组；存在其他组、进程重启后残留组一律不自动接管。超时或进程被杀后可能需在系统Wi-Fi设置处理残留组。

日志不含密码或客户端身份；P2P页面禁止截图，密码只在该页显示。没有开机恢复或自动切换网络。开发签名可能与0.1不同，签名冲突时需卸载旧助手重新安装。

验收：能打开P2P页面；能建组并读到有效信息；iPhone可尝试接入；切到主页服务仍在；停止后本组消失。建组成功不代表无线CarPlay成功，需后续单独验证蓝牙/iAP2/AirPlay。
